# BuildIn — site web
 
Site vitrine de l'association BuildIn : présentation, réalisations et contact.
Site 100 % statique (HTML + CSS), sans framework ni étape de build.
 
## Structure
 
```
index.html   contenu de la page
style.css    styles et couleurs de la charte graphique
images/      logo, mascotte, favicon
fonts/       polices auto-hébergées (Fredoka, Nunito)
```
 
## Modifier le site
 
1. Éditer `index.html` (textes, projets) ou `style.css` (apparence), directement sur GitHub ou en local.
2. Commit sur `main` : Cloudflare redéploie automatiquement en ~1 minute.
Pour tester en local : ouvrir `index.html` dans un navigateur.
 
## Hébergement
 
Déployé sur Cloudflare (offre gratuite), connecté à ce dépôt.
